# AndThenn end-to-end audit — 04 August 2026

## Release conclusion

The current build is **not release-ready** and 100% feature operation cannot be verified. It is a polished, mostly static showcase with a small number of local interactions and API/domain building blocks. The PRD's end-to-end operating lifecycle is not connected through the UI.

No application feature behavior was changed during this audit. The only code changes are the Playwright audit suite and test-runner isolation so unit tests do not execute stale `dist/` files or Playwright specs.

## In-app browser walkthrough

The production build was exercised in the in-app browser on the default desktop viewport and at 375×812, following `docs/testing/manual-e2e-guide.md`.

Of 73 directly observable browser checks, **17 passed and 56 failed**. Environment-dependent gates are listed separately as blocked, not counted as passes.

Verified working:

- Root redirects to `/home`.
- All nine primary navigation destinations tested open the expected page.
- Global search opens and accepts text; closing works.
- The initially displayed intake item can be released and reclaimed in local component state.
- Project Board/List toggling works in local component state.
- Desktop review play/pause and comment-marker selection work.
- Mobile navigation and the mobile review comments drawer open.

Verified broken:

- Global search results do not navigate.
- Header **New**, **Help & support**, and profile controls do nothing.
- Both login buttons do nothing.
- Selecting Northstar in Intake changes the active row but leaves the Monsoon detail pane displayed.
- All eight tested Intake actions/attachments/filters are inert.
- Project and client search fields accept text but do not filter.
- `/projects/juniper` renders the hard-coded Monsoon Stories workspace.
- Proposal, project, and task create/edit/status/upload/comment actions are inert.
- Client, commercial, report, notification, workload, and admin actions are inert.
- Workload week navigation and cell drill-down do nothing.
- Review feedback does not submit or persist; share, download, more, fullscreen, reviewer identity, and draw controls do nothing.
- Review playback does not enter the playing state on mobile after the comments drawer is closed.
- The task detail page overflows horizontally at 375 px.

## Blocked release gates

These PRD gates cannot be completed with the supplied local showcase and configuration:

- Credential-backed Google authentication and the full permanent/temporary role matrix.
- Real Gmail, WhatsApp, AI, and storage sandbox recovery/retry.
- Persistent database CRUD and reload checks.
- Version-pinned review using two actual versions and all four media types.
- Backup restore and archive verification.
- Screen-reader review, realistic-volume performance test, security penetration test, manager UAT, and ownership/credential handover.

## Highest-priority defects

1. **P0 — No usable system of record.** Most screens read static demo arrays and most mutating controls have no handler or persistence.
2. **P0 — Authentication is not enterable.** Both login actions are inert; role/expiry/scoping cannot be exercised.
3. **P0 — Core request-to-project path is broken.** Intake selection, attachments, save, conversion, proposal actions, activation, and project creation do not form a workflow.
4. **P0 — Project identity is wrong.** Every `/projects/[id]` renders the same hard-coded project.
5. **P0 — Delivery and review cannot complete.** Status change, upload, internal comment, external feedback, approval, closure, and archive workflows are not usable.
6. **P1 — Operations are display-only.** Search/filter/drill-down/export/notification/admin controls do not work.
7. **P1 — Mobile defects.** Task detail horizontally overflows and review playback fails in the tested mobile sequence.

## Reproduction

```bash
pnpm install --offline
pnpm check
pnpm e2e
pnpm e2e:report
```

The E2E command is expected to exit non-zero until the 56 recorded failures are fixed. A release candidate should not weaken or skip those assertions.
