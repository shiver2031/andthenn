# PRD-CR-001: Light-first theme direction

- Status: Approved
- Date: 2026-08-04
- Authority: User-approved implementation-plan decision

## Decision

The ERP uses a light-first operational theme. Manager command-centre, authentication, media-review, and completion experiences may default to the dark control-room theme. Both modes use the same semantic information hierarchy, interaction behavior, permissions, states, and accessibility requirements.

## Constraint

This visual exception does not change any PRD workflow, role, permission, lifecycle, business rule, state transition, data relationship, acceptance signal, or release gate.
